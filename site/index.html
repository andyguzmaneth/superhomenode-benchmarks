superhomenode-benchmarks

Performance benchmarks of different implementations of the same PIR scheme, on one frozen home-staker machine, over databases shaped like Ethereum state. Reference spec follows the staking tier of ethereum.org/run-a-node. Security levels shown are claimed by each implementation and are not verified here.

Not reference data. Some rows were produced on a host that did not match the frozen reference machine, and are labelled UNVERIFIED — treat shapes as real, absolute numbers as provisional.
